# Friend Hub sürümleri

Bu depo yalnızca Friend Hub Windows kurulum paketlerini ve otomatik güncelleme dosyalarını (`latest.yml`, `.blockmap`, `.sig` imzaları) barındırır. Kaynak kod ayrı, özel bir depodadır.

Sürümler ana depodaki GitHub Actions iş akışı tarafından otomatik yayımlanır. İndirmek için [Releases](../../releases/latest) sayfasındaki `Friend-Hub-Setup-<sürüm>.exe` dosyasını kullanın; kurulumdan sonra uygulama kendini günceller.
